.. py:function:: render_keystone_svg() -> str

   Render a 1:1 50 mm x 50 mm SVG reticle mask for Plate 0 (Vesica Keystone).

   Evaluates exact SymPy algebraic coordinates from :func:`build_keystone_plate_model`
   strictly at the SVG serialization boundary, mapping unit chord ``|AB| = 1``
   to ``unit_chord_mm = 20 mm`` centered on a ``50 mm x 50 mm`` quartz reticle.

   :returns: Complete SVG document string with physical ``mm`` dimensions and ``.euclid-graphic`` styling.


.. py:function:: export_plate_svg(output_path: pathlib.Path) -> pathlib.Path

   :param output_path: Destination file path for the generated SVG.

   :returns: Resolved path to the written SVG file.
