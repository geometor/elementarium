geometor.elementarium.plates.render_keystone_svg() → str¶

Render a 1:1 50 mm x 50 mm SVG reticle mask for Plate 0 (Vesica Keystone).

Evaluates exact SymPy algebraic coordinates from build_keystone_plate_model() strictly at the SVG serialization boundary, mapping unit chord |AB| = 1 to unit_chord_mm = 20 mm centered on a 50 mm x 50 mm quartz reticle.

Returns:

Complete SVG document string with physical mm dimensions and .euclid-graphic styling.
