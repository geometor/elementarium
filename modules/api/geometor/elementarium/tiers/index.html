geometor.elementarium.tiers.brewster_spread(refractive_index: sympy.Expr = FUSED_SILICA_ND) → sympy.Expr¶

Compute exact Rational Trigonometry spread s_B = n^2 / (1 + n^2) for Brewster’s angle.

Because tan(theta_B) = n, sin^2(theta_B) = n^2 / (1 + n^2) is strictly rational whenever the refractive index is rational.

Parameters:

refractive_index – Exact symbolic refractive index n of the dielectric medium.

Returns:

Exact symbolic spread s_B in [0, 1].
